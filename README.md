# 霓虹環道 Neon Circuit

原創街機風格 3D 生涯賽車。玩家從入門車「雲雀 Mk.I」起步，與 7 台 AI 同場競技，賺取獎金、收集星星、升級與買車，挑戰銀線車隊。

## 啟動方式

```bash
npm install
npm run dev
```

開發伺服器會在本機開啟遊戲。使用現代桌面瀏覽器（Chrome / Edge）遊玩。

正式建置：

```bash
npm run build
npm run preview
```

本專案使用固定版本的 [Three.js](https://threejs.org/)（見 `package.json`），無需 API Key 或後端。

## 操作

| 按鍵 | 功能 |
| --- | --- |
| W / ↑ | 加速 |
| S / ↓ | 煞車與倒車 |
| A / ← | 左轉 |
| D / → | 右轉 |
| Space | 手煞車／漂移 |
| R | 重置到最近的有效賽道位置 |
| Esc | 暫停 |

倒數結束前車輛無法起步。必須依序通過檢查點才會計算圈數，逆向或抄捷徑無法完賽。

## 遊戲內容

- 1 個故事章節「夜城入場券」
- 6 場正式關卡（3 種賽道配置：港灣迴環、城芯街道、雲脊山道，含正向／逆向、天候與圈數變化）
- 10 台原創車輛：雲雀、流火、赤隼、青鷺、鐵鯨、迅狸、弧光、夜鯊、彗星、幻影
- 每場 8 車（玩家 + 7 AI），AI 駕駛不同車款
- 三星評價、關卡解鎖、獎金
- 車庫、車店（對比數據）、五類升級、車色／輪圈／金屬感自訂
- 賽前可直接切換已擁有車輛
- localStorage 自動存檔

## 專案結構

```
src/game/          賽道、物理、AI、比賽、存檔、音效
src/game/data/     車輛、關卡、故事、升級數值
src/store/         生涯狀態
src/components/game/ 中文介面
src/routes/        應用入口
```

## 已知限制

- 車輛與賽道為低多邊形程序生成，非寫實模擬器。
- 無線上多人、無開放世界、無車損系統。
- 行動裝置提供簡易觸控，體驗以桌面鍵盤為主。
- 音效為 Web Audio 合成，非錄音採樣。

## 測試

```bash
node --experimental-strip-types --test src/game/sim.test.ts
```

頭測涵蓋賽道生成、存檔容錯、獎金不重複、升級改物理，以及 AI 能否跑完港灣熱身。
